Política de Privacidade do Mavs

Última atualização: 23 de outubro de 2026.

O Mavs é um assistente pessoal por voz de uso particular, criado e usado por uma única pessoa, o próprio desenvolvedor. Não é um serviço oferecido ao público.

Quais dados o Mavs acessa

  • Google Agenda: lê, cria e apaga compromissos da conta do próprio usuário.
  • Gmail: acesso somente leitura aos e-mails da conta do próprio usuário. O Mavs não envia, não responde e não apaga e-mails.

Como os dados são usados

Os dados são usados apenas para responder às perguntas do usuário e mostrar avisos (por exemplo, compromissos e e-mails novos). Não são vendidos, compartilhados com terceiros nem usados para publicidade.

Onde os dados ficam

O login e as informações ficam no computador do próprio usuário. Quando o usuário faz uma pergunta que envolve agenda ou e-mail, o trecho necessário é enviado ao modelo de IA (Gemini, do Google) para gerar a resposta. Senhas e códigos de verificação são removidos antes.

Como revogar o acesso

O acesso pode ser removido a qualquer momento em myaccount.google.com/permissions.

Uso dos dados do Google

O uso das informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.
